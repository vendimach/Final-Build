# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Commands

```bash
npm run dev        # start Vite dev server
npm run build      # production build → dist/
npm run lint       # ESLint
npm run format     # Prettier (writes in place)
```

No test suite is configured. There is a `bun.lockb` but the project uses `npm` scripts.

## Environment variables

Create a `.env` file at the project root:

```
VITE_SUPABASE_URL=...
VITE_SUPABASE_PUBLISHABLE_KEY=...
```

Netlify Functions also need (set in Netlify dashboard, not `.env`):
```
RAZORPAY_KEY_ID=...
RAZORPAY_KEY_SECRET=...
```

## Architecture

**Stack:** React 19 · TanStack Router · TanStack Query · Vite · Tailwind CSS v4 · shadcn/ui (Radix UI) · Supabase · Netlify

### Routing

TanStack Router with file-based routes under `src/routes/`. **Never edit `src/routeTree.gen.ts` manually** — it is auto-generated by the TanStack Router plugin on every Vite run.

Route layout:
```
/                   → src/routes/index.tsx
/shop               → src/routes/shop.tsx        (layout with Outlet)
  /shop/            → src/routes/shop.index.tsx  (product grid)
  /shop/$slug       → src/routes/shop.$slug.tsx  (PDP)
/build-your-box     → custom bundle builder
/checkout           → Razorpay checkout
/order-confirmed    → post-payment confirmation
/auth               → email/password + phone OTP + Google OAuth
/dashboard          → customer orders, wallet, referrals
/track              → order tracking
/subscribe          → subscriptions
/admin              → layout (role-gated via has_role RPC)
  /admin/           → overview
  /admin/orders, /admin/products, /admin/bundles, /admin/coupons, /admin/customers
```

### Product data — two sources

`src/lib/products.ts` — static fallback data (hardcoded). The `Product` type lives here.

`src/lib/db-products.ts` — live Supabase data. `fetchProducts()` queries the `products` table. `dbToProduct()` converts a DB row to `Product`.

Critical distinction in the `Product` type:
- `product.id` = URL slug (used for `/shop/$slug` routing)
- `product.dbId` = DB UUID (used for `order_items.product_id` foreign key)

### Global providers (src/routes/__root.tsx)

`AuthProvider` → `CartProvider` → page content. Both wrap the entire app. `CartDrawer` and `Toaster` are also mounted here.

The root also handles the referral flow: `?ref=CODE` in the URL is saved to `localStorage` as `pending_referral_code`, then processed via the `process_referral_signup` Supabase RPC when the user signs in.

### Cart (src/lib/cart-context.tsx)

Persisted in `localStorage` per user (`vendiman.cart.user.<uid>`) or guest (`vendiman.cart.guest`). On sign-out the in-memory cart is wiped immediately. `MAX_PER_ITEM = 15` is enforced on `addItem`/`updateQty`; `maxStock` on an item can set a lower hard ceiling.

### Auth (src/lib/auth-context.tsx)

Thin wrapper around `supabase.auth`. Exposes `{ user, session, loading, signOut }`. Import via `useAuth()`.

Admin access is checked at runtime with `supabase.rpc("has_role", { _user_id, _role: "admin" })` — this queries the `user_roles` table.

### Payments

Razorpay is the only payment gateway. Flow:
1. Client calls `/.netlify/functions/create-razorpay-order` (POST, `{ amount, receipt }`) — this keeps the secret key server-side.
2. Client opens the Razorpay JS modal (`RazorpayCheckout` component).
3. On success, `verify-razorpay-payment` Netlify function validates the HMAC signature.
4. `checkout.tsx` then inserts into `orders` + `order_items` and calls `process_first_order_referral`.

All prices are in **INR as plain rupee numbers** (not paise). Use `formatINR()` from `src/lib/currency.ts` for all displayed amounts. Free shipping threshold: ₹499. Flat shipping fee: ₹49.

### Supabase

Client singleton at `src/integrations/supabase/client.ts` — import as `import { supabase } from "@/integrations/supabase/client"`.

Generated types at `src/integrations/supabase/types.ts` — update these when the DB schema changes.

Key RPC functions: `has_role`, `process_referral_signup`, `process_first_order_referral`, `credit_order_wallet`.

The wallet system credits cashback on delivery via a DB trigger calling `credit_order_wallet`; `wallet_transactions` records every credit/debit.

### UI components

`src/components/ui/` contains shadcn/ui components — do not hand-edit these. Custom app components live directly in `src/components/`.

The `@/` path alias resolves to `src/`.

### Deployment

Netlify. `netlify.toml` sets `publish = "dist"` and a catch-all SPA redirect. Serverless functions are in `netlify/functions/` (ES module `.mjs` files using the Web-standard `Request`/`Response` API, not the legacy `event`/`context` handler).
